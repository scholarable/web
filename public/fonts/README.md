# Self-hosted fonts

Font files are served locally so page views do not request Google Fonts.

- `inter-latin.woff2`: Inter Latin variable font, used at weights 400–800 for text. [Google Fonts asset](https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTeHuS_nVMrMxCp50SjIa1ZL7W0Q5nw.woff2). License: `inter-OFL.txt`, copied unchanged from [google/fonts](https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt).
- `bricolage-latin.woff2`: Bricolage Grotesque Latin variable font (weights 200–800, optical size 12–96), used for headings and amounts. [Google Fonts asset](https://fonts.gstatic.com/s/bricolagegrotesque/v9/3y9K6as8bTXq_nANBjzKo3IeZx8z6up5BeSl9D4dj_x9PpZBMlGIInHWVyNJ.woff2). License: `bricolage-OFL.txt`, copied unchanged from [google/fonts](https://github.com/google/fonts/blob/main/ofl/bricolagegrotesque/OFL.txt).

Both font families are distributed under the SIL Open Font License 1.1. The original licenses and copyright notices are included alongside the font files.
